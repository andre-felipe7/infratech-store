Sobre a InfraTech Store

A InfraTech Store é uma loja de demonstração criada como projeto educativo. Aqui você pode conhecer os produtos e testar as etapas de uma compra, sem realizar pagamentos reais.

O site foi desenvolvido com HTML, CSS e JavaScript básicos para praticar a organização das páginas, os estilos e as interações com o usuário.

Como comprar nesta demonstração

  1. Escolha os produtos e clique em “Adicionar ao carrinho”.
  2. Confira as quantidades no carrinho e entre na sua conta de demonstração.
  3. Selecione a forma de pagamento e confirme o pedido de teste.

Dica: use o cupom INFRA10 para testar um desconto de 10%.
