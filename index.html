Sobre a InfraTech Store

A InfraTech Store é uma loja de demonstração criada como projeto educativo. Aqui você pode conhecer os produtos e testar as etapas de uma compra, sem realizar pagamentos reais.

O site foi desenvolvido com HTML, CSS e JavaScript básicos para praticar a organização das páginas, os estilos e as interações com o usuário.

Como comprar nesta demonstração

  1. Escolha os produtos e clique em “Adicionar ao carrinho”.
  2. Confira as quantidades no carrinho e entre na sua conta de demonstração.
  3. Selecione a forma de pagamento e confirme o pedido de teste.

Dica: use o cupom INFRA10 para testar um desconto de 10%.

Termos de Uso

A InfraTech Store é um projeto educativo. Cadastros, pedidos, pagamentos e entregas são simulações: não há venda, cobrança ou envio de produtos. Use apenas dados fictícios e uma senha de demonstração.

Aviso de Privacidade

O cadastro guarda usuário, e-mail, senha de demonstração, endereços e o registro deste aceite para permitir acesso à conta, escolha de entrega e simulação de compras. Mensagens enviadas pelo formulário de contato também são guardadas.

Esses dados ficam no armazenamento local deste navegador, até serem excluídos. Não são enviados a um servidor pela aplicação. Quem tiver acesso ao navegador pode acessar esses dados; o painel demonstrativo exibe usuários, e-mails e mensagens. Não use dados pessoais ou senhas reais.

Os dados do cartão são usados apenas para validar o formato na simulação e não são armazenados. O GitHub Pages hospeda o site e pode tratar dados técnicos de acesso conforme sua própria política de privacidade.

Para consultar os endereços, entre na conta e abra a finalização da compra. Para excluir o cadastro local e retirar a autorização, remova os dados deste site nas configurações de privacidade do navegador. Isso também apaga contas, endereços e demais dados da demonstração nesse navegador.

Não usamos este aceite como autorização para marketing. Versão dos termos e do aviso: 28/10/2026.
